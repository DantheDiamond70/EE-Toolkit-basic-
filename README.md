# EE-Toolkit
Ohm's law Calculator in Python

suitable for students and beginners learning Python

## Features
- it can calculate voltage, current and resistance using Ohm's Law
- asks again if you typed something wrong

## How to run
1. install Python for desktop and laptop users
2. download `toolkit.py`
3. open a terminal in the folder and type `python toolkit.py`

for mobile users, you can paste the code into any Python app and run it

## Example
```
===EE TOOLKIT===

Ohm's Law

Calculate?: V, I, R (or quit) V
Calculating Voltage: 

Enter amount of Current (or quit): 10.0
enter amount of Resistance: 5.0
voltage: 50.0 V
Continue, Main menu or Quit?

```
